## コマンド一覧

### API

| コマンド | 説明 |
|---|---|
| `npm run dev` | 開発サーバー起動 |
| `npm run lint` | Lintチェック |
| `npm run format` | フォーマット |
| `npm test` | テスト実行 |
| `npx drizzle-kit generate` | マイグレーションファイル生成 |
| `npx drizzle-kit migrate` | マイグレーション実行 |
| `npx drizzle-kit studio` | Drizzle Studio起動（DB確認用GUI） |

### Web

| コマンド | 説明 |
|---|---|
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | ビルド |
| `npm run lint` | Lintチェック |
| `npm run format` | フォーマット |
| `npm test` | テスト実行 |
| `npm run generate` | orvalでAPIクライアント生成 |

### Supabase

| コマンド | 説明 |
|---|---|
| `npx supabase start` | ローカルSupabase起動 |
| `npx supabase stop` | ローカルSupabase停止 |
| `npx supabase status` | 接続情報確認 |
